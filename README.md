# Digital Velvet Voice Engine

Internal Digital Velvet tooling for matching live vocal performance to the expected production identity of released tracks.

## Goal
Build an internal workflow that:
- analyzes a reference vocal stem
- extracts a vocal fingerprint
- generates a live vocal chain
- helps live vocals land closer to the released sound

## Scope
Internal only. No external commercialization planned.

## Main folders
- Docs/ design and architecture
- analysis/ Python prototypes for vocal fingerprint extraction
- plugin/ JUCE plugin source later
- presets/ saved song profiles
- assets/ reference and test material
